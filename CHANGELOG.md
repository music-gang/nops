# Changelog

What changed in each release of Nops that someone running it would notice,
newest first. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the versions
follow the rules in [Releasing](docs/development.md#releasing): while Nops is
at 0.x a minor release may break things, and each break is a line starting
with **Breaking:** that says what to do when upgrading.

The notes of the releases up to 0.4.0 are on the
[GitHub Releases](https://github.com/music-gang/nops/releases) page.
